
# Overview

**RoboCasa365** is a large-scale simulation framework for training generally capable robots to perform everyday tasks. Four pillars underlie RoboCasa:
- **Diverse tasks**: 365 tasks created with the guidance of large language models
- **Diverse assets**: including 2,500+ kitchen scenes and 3,200+ 3D objects
- **High-quality demonstrations**: including 600+ Hr of human demonstrations in addition to 1,600+ Hr of robot datasets created with automated trajectory tools
- **Cross-embodiment support** for mobile manipulators and humanoid robots

RoboCasa365 builds upon the [original RoboCasa release](https://robocasa.ai/assets/robocasa_rss24.pdf), released in 2024 by UT Austin.

This documentation guide contains information about installation, getting started, and additional use cases such as accessing datasets, policy learning, and API docs.
